# Changelog

All notable changes to DeckShelf are documented here. The project follows [Semantic Versioning](https://semver.org/) and uses Conventional Commits to prepare releases.

## 1.0.0 - 2026-08-16

### Added

- Portable Rust desktop applications for Windows, Linux, macOS Apple Silicon, and macOS Intel.
- A self-contained browser version deployed through GitHub Pages.
- EmuDeck and RetroDECK-aware scanning with configurable systems and exclusions.
- Search, filters, favourites, wanted-list checking, storage views, and export tools.
- Portable settings, WebView data, and a browser fallback for Windows startup failures.
- Cross-platform CI, release checksums, build provenance, and automated semantic version preparation.
